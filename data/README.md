# Data

All data in this repository is synthetic. Materials, plants, suppliers, and
forwarders are fictional. Relationships between fields are designed to be
plausible, but they are not real statistics.

| Folder | In Git | Purpose |
|---|---|---|
| `seed/` | Yes | Starting state for every demo run and test. Generated by `scripts/generate_seed.py`; do not edit by hand. |
| `runtime/` | No | Working copy that the tools read and write during a run. Replaced on every reset. |

Reset before each demo run:

```
python scripts/reset_data.py
```

## Generator rules

To be written together with the generators in `src/clear_datagen/`. This
